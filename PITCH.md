# 60-second pitch (fill in on the spot)

1. **Problem (10s)** — "[Specific person] wastes [time/money] every [day/week] because [painful step]."
2. **Solution (10s)** — "[App name] lets them [paste/upload/describe X] and get [concrete output] in seconds."
3. **Live demo (30s)** — One real example input → show the result card. Don't explain the code.
4. **Why it's agentic (5s)** — "It doesn't just answer; it [extracts / decides / produces a ready-to-use X]."
5. **Built with (5s)** — "Built in Antigravity with Gemini, deployed on Cloud Run."

Tips: have the demo input copied to clipboard. Open the live URL before you walk up. If wifi dies, show localhost.
